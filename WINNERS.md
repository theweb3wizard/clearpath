## Losing patterns (institutions now DQ for several)
1. Graph/MCP as decoration (FalkorDB removal test — our README proves the opposite).
2. Missing baseline requirements (eligibility screen first — our R10 package is complete).
3. Shoehorned idea / ignoring track bullets (our brief maps 1:1 to T1+T2 focus lists).
4. Template reskin / relabeled prior project (100% fresh FalkorDB core; Bursar code stays out).
5. Slick video, empty repo / doesn't install (judges pull and run — our setup is one page).
6. Slides-only / confusing demo (90-second demo-first video, pre-filled cases, zero stalls).
7. Scope creep: 5 half-features (ONE question end-to-end: "can I trust this counterparty?").
8. AI-generated without understanding (we disclose tools AND can whiteboard every query).
9. No explainability (every verdict = path + sources + confidence, or it doesn't ship).
